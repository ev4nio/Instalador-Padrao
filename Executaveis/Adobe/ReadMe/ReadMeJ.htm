Adobe® Acrobat® XI Pro および Standard ソフトウェア

 

Adobe® Acrobat® XI Pro および Adobe Acrobat XI Standard の ReadMe へようこそ。このドキュメントには、Adobe Acrobat 製品に関する重要な情報が記載されています。すべての製品に該当する ReadMe の項目には製品名を指定していません。Adobe Acrobat XI の製品サポート情報については、http://www.adobe.com/go/acrobat_support_jp を参照してください。

 

必要システム構成

 

Acrobat XI Pro for Windows® の必要システム構成は以下のとおりです。

 

·         1.3 GHz 以上のプロセッサー

·         32 ビット版 Microsoft® Windows XP に SP 3 を適用したもの（64 ビット版の場合は SP 2）、Windows Server® 2003 R2（32 ビット版と 64 ビット版）、Windows Server 2008 または 2008 R2（32 ビット版と 64 ビット版）、Windows 7（32 ビット版と 64 ビット版）、Windows 8（32 ビット版と 64 ビット版）

·         512 MB の RAM（1 GB 推奨）

·         1.9 GB のハードディスク空き容量（注意：インストール時にインストーラーが一時ファイルを作成します。このため、インストール時に実際に必要なハードディスクの空き容量はこの値よりも大きくなります。）

·         1,024 x 768 画面解像度

·         Internet Explorer 7、8、9、10、Firefox（ESR）、Chrome

·         DVD-ROM ドライブ（DVD からインストールを行う場合）

·         ビデオハードウェアアクセラレーション（オプション）

64 ビット版 Windows Server 2003 SP2 および Windows XP SP2 の場合は、Microsoft 社の修正プログラム KB-930627 をインストールする必要があります。以下を参照してください。

http://support.microsoft.com/kb/930627/ja

 

 

Acrobat XI Standard for Windows® の必要システム構成は以下のとおりです。

 

·         1.3 GHz 以上のプロセッサー

·         32 ビット版 Microsoft® Windows XP に SP 3 を適用したもの（64 ビット版の場合は SP 2）、Windows Server® 2003 R2（32 ビット版と 64 ビット版）、Windows Server 2008 または 2008 R2（32 ビット版と 64 ビット版）、Windows 7（32 ビット版と 64 ビット版）、Windows 8（32 ビット版と 64 ビット版）

·         512 MB の RAM（1 GB 推奨）

·         1.5 GB のハードディスク空き容量（注意：インストール時にインストーラーが一時ファイルを作成します。このため、インストール時に実際に必要なハードディスクの空き容量はこの値よりも大きくなります。）

·         1,024 x 768 画面解像度

·         Internet Explorer 7、8、9、10、Firefox（ESR）、Chrome

·         DVD-ROM ドライブ（DVD からインストールを行う場合）

·         ビデオハードウェアアクセラレーション（オプション）

64 ビット版 Windows Server 2003 SP2 および Windows XP SP2 の場合は、Microsoft 社の修正プログラム KB-930627 をインストールする必要があります。以下を参照してください。

http://support.microsoft.com/kb/930627/ja

 

インストール方法

 

以下の手順に従って、新しいソフトウェアをインストールするか、以前のバージョンからアップグレードしてください。アップグレードをインストールする場合は、製品の正規ユーザーである必要があります。

 

Windows に Acrobat XI をインストールするには

 

1. Windows を再起動してウイルス対策ソフトウェアを無効にします。

 

2. コンピューターをインターネットに接続します。

 

3. 次の手順に従ってインストールを開始します。

  • DVD 版の Acrobat を購入した場合は、DVD を挿入します。
  • ダウンロード版の Acrobat を購入した場合は、ハードディスク上の任意の場所にパッケージをダウンロードします。

 

ソフトウェアをインストールする前に、ダウンロードパッケージを DVD にバックアップしておくことをお勧めします。.exe をダブルクリックすると、以下の場所に解凍することができます。

 

Windows XP オペレーティングシステムの場合：

 

<システムドライブ>:\Documents and Settings\<ユーザー>\Desktop\Adobe Acrobat XI フォルダーがデスクトップに作成されます。

 

Windows 7 および 8 オペレーティングシステムの場合：

 

<システムドライブ>:\users\<ユーザー名>\Desktop\Adobe Acrobat XI フォルダーがデスクトップに作成されます。

 

インストールの準備ができたら、Adobe Acrobat XI フォルダーを開いて setup.exe をダブルクリックします。

 

Adobe Acrobat XI セットアップダイアログボックスで、言語を選択し、「OK」をクリックします。必ず購入した言語を選択してください。「Adobe Acrobat XI セットアップ」画面で「次へ」をクリックします。インストーラーは必要なディスク容量を計算し、前のバージョンを確認します。前のバージョンの Acrobat 製品が見つかった場合は、「続行」をクリックしてアンインストールします。

 

4. セットアップ画面が表示され、ユーザー名、組織およびシリアル番号を入力するよう求められます。体験版モードで製品を使用する場合やサブスクリプションを購入済みの場合 （Pro のみ） は、シリアル番号を入力する必要はありません。シリアル番号を入力する際は、コンピューターがインターネットに接続されていることを確認してください。これは、オンラインの状態でないとシリアル番号が検証されないためです。注意：体験版モードでインストールを行った場合、ソフトウェアを使用できるのは初回起動日から 30 日間になります。

 

5. プログラムのインストール用のシリアル番号を入力します。ライセンスを取得した個々の購入製品のシリアル番号は、DVD ケースの外側、またはアドビストアで購入した ESD（電子ソフトウェアダウンロード）製品の確認ページに記載されています。ライセンスを取得した個々の ESD 製品のシリアル番号は、http://www.adobe.com/jp/ のオンライン注文履歴にも記載されています。アドビライセンス Web サイトで購入した製品のシリアル番号は、http://licensing.adobe.com で確認できます。

 

6. 「アドビライセンス認証」画面で「次へ」をクリックします。ライセンス認証は、ソフトウェアが匿名で行うシンプルな一連の手順です。製品のライセンス認証について詳しくは、アドビの Web サイト（http://www.adobe.com/go/activation_jp/）を参照してください。

 

7. インストールの種類を選択します。

  • 「標準」（デフォルト）を選択すると、Acrobat、Acrobat Distiller、PDFMaker のプログラムファイル、システム用の Adobe PostScript プリンタードライバー、標準のプラグインおよびアクセサリがインストールされます。
  • 「すべて」を選択すると、Acrobat XI のすべての機能がインストールされます。最大のディスク容量が必要です。
  • 「カスタム」を選択すると、インストールするコンポーネントを指定できます。

 

注意：コンポーネントの説明を確認するには、「カスタム」を選択し、「次へ」をクリックします。次に、説明を確認するコンポーネントを選択します。カスタムインストールを続行せず、インストールの種類の選択に戻るには、「戻る」をクリックします。

 

「次へ」をクリックします。必要に応じてインストール先のディレクトリを変更するか、またはデフォルトのディレクトリが表示されている状態で、「次へ」をクリックします。

 

8. 「インストール」をクリックすると、インストールが続行します。インストールと競合するプロセスが実行されている場合、インストーラーは、インストールを続行できるようになる前にこれらのプロセスを停止するよう求める画面を表示します。プロセスを閉じてからインストーラーをクリックし、インストールを続行します。

 

9. 最後のダイアログは「セットアップが完了しました」です。「完了」をクリックします。これで Acrobat を起動できるようになりました。

 

10. Acrobat を起動してエンドユーザー使用許諾契約書に同意し、ソフトウェアを使用できるようにします。

 

11. インストール時にシリアル番号を入力した場合は、次の手順 12 を参照してください。Acrobat を体験版モードで使用する場合や、Acrobat をサブスクリプションに使用する場合（Pro のみ）は、「サインインが必要です」画面が表示されます。「サインインが必要です」画面で「今すぐサインイン」を選択します。「サインイン」画面で、Adobe ID を入力します。Adobe ID を作成していない場合は「Adobe ID の作成」をクリックして、必要事項を入力します。入力したら、「作成」をクリックします。画面の指示に従い、作成プロセスを完了します。「サインイン」をクリックします。これで Acrobat が使用できるようになりました。

 

12. インストール時にシリアル番号を入力した場合は、「登録」画面が表示されます。「登録」画面で、Adobe ID を入力します。Adobe ID を作成していない場合は「Adobe ID の作成」をクリックして、必要事項を入力します。入力したら、「作成」をクリックします。画面の指示に従い、Adobe ID の作成および登録プロセスを完了します。オプションとして、「スキップ」を選択することもできます。重要：ソフトウェアのコピーのライセンス認証を行うには、インターネットに接続する必要があります。ライセンス認証は 30 日以内に行ってください。30 日を経過すると、ソフトウェアを使用できなくなります。

 

Windows で Acrobat XI をアンインストールするには

 

1. Acrobat XI をアンインストールする前に、製品のライセンス認証を解除します。そのためには、ヘルプ／ライセンス認証の解除を選択します。アンインストールを行うには、コントロールパネルを起動し、「プログラムの追加と削除」（XP）または「プログラムと機能」（Windows 7 および 8）を選択します。

 

2. 表示されるアプリケーションのリストで、「Acrobat XI」を選択して「削除」ボタン（XP）または「アンインストール」ボタン（Windows 7 および 8）をクリックします。

 

3. Acrobat を削除するかどうかを確認するダイアログが表示されます。「はい」をクリックして製品をアンインストールします。

登録

 

Acrobat を起動すると、サインインしてソフトウェアを登録するよう求められます。テクニカルサポートを利用するには、登録を行う必要があります。
