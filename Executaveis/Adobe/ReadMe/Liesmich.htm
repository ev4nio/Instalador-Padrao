Adobe® Acrobat® XI Pro- und Standard-Software

 

Dies ist die ReadMe-Datei zu Adobe® Acrobat® XI Pro und Adobe Acrobat XI Standard. Sie enthält wichtige Informationen über Adobe Acrobat-Produkte. Im Hinblick auf Informationen in der ReadMe-Datei, die für alle Produkte gelten, wird der Produktname nicht genannt.d Informationen zum Produktsupport für Adobe Acrobat XI erhalten Sie unter http://www.adobe.com/go/acrobat_support_de.

 

Systemanforderungen

 

Systemanforderungen für Acrobat XI Pro für Windows®:

 

•         Prozessor mit mindestens 1,3 GHz

•         Microsoft® Windows XP mit SP3 bei 32-Bit (mit SP2 bei 64-Bit); Windows Server® 2003 R2 (32-Bit und 64-Bit); Windows Server 2008 oder 2008 R2 (32-Bit und 64-Bit); Windows 7 (32-Bit und 64-Bit); Windows 8 (32-Bit und 64-Bit)

•         512 MB RAM (empfohlen wird 1 GB)

•         1,9 GB freier Festplattenspeicher (Hinweis: Das Installationsprogramm erstellt während der Installation temporäre Dateien. Daher ist der tatsächliche Bedarf an Festplattenspeicher zu diesem Zeitpunkt größer als die hier angegebene Menge.)

•         Bildschirmauflösung von 1024 x 768

•         Internet Explorer 7, 8, 9, 10; Firefox (ESR); Chrome

•         DVD-ROM Laufwerk (bei Installation von einem Laufwerk) DVD

•         Optionale Videohardwarebeschleunigung

Bei Windows Server 2003 SP2 und Windows XP SP2 für 64-Bit wird das Microsoft Hot Fix KB-930627 benötigt. Siehe:

http://support.microsoft.com/kb/930627

 

 

Systemanforderungen für Acrobat XI Standard für Windows®:

 

•         Prozessor mit mindestens 1,3 GHz

•         Microsoft® Windows XP mit SP3 bei 32-Bit (mit SP2 bei 64-Bit); Windows Server® 2003 R2 (32-Bit und 64-Bit); Windows Server 2008 oder 2008 R2 (32-Bit und 64-Bit); Windows 7 (32-Bit und 64-Bit); Windows 8 (32-Bit und 64-Bit)

•         512 MB RAM (empfohlen wird 1 GB)

•         1,5 GB freier Festplattenspeicher (Hinweis: Das Installationsprogramm erstellt während der Installation temporäre Dateien. Daher ist der tatsächliche Bedarf an Festplattenspeicher zu diesem Zeitpunkt größer als die hier angegebene Menge.)

•         Bildschirmauflösung von 1.024 x 768

•         Internet Explorer 7, 8, 9, 10; Firefox (Extended Support Release); Chrome

•         DVD-ROM Laufwerk (bei Installation von einem Laufwerk) DVD

•         Optionale Videohardwarebeschleunigung

Bei Windows Server 2003 SP2 und Windows XP SP2 für 64-Bit wird das Microsoft Hot Fix KB-930627 benötigt. Siehe:

http://support.microsoft.com/kb/930627

 

Installationsanweisungen

 

Anhand der folgenden Anweisungen können Sie die neue Software installieren oder ein Upgrade einer älteren Version durchführen. Bei Installation eines Upgrades ist eventuell ein Eigentumsnachweis erforderlich.

 

So installieren Sie Acrobat XI unter Windows

 

1. Starten Sie Windows neu und deaktivieren Sie etwaige Virenschutzprogramme.

 

2. Verbinden Sie den Computer mit dem Internet.

 

3. Beginnen Sie mit der Installation:

  • Wenn Sie Acrobat auf einer DVD erworben haben, legen Sie die DVD ein.
  • Haben Sie Acrobat als Download erworben, laden Sie das Paket auf Ihre Festplatte herunter.

 

Adobe empfiehlt vor der Installation der Software, das Downloadpaket zu sichern, und zwar bevorzugt auf einer DVD. Nachdem Sie zum Entpacken des Pakets auf die Datei mit der Endung „.exe“ geklickt haben, geschieht Folgendes:

 

Unter Windows XP

 

<wird der Ordner „Systemlaufwerk >:\Dokumente und Einstellungen\<Benutzer>\Desktop\Adobe Acrobat XI“ auf dem Desktop erstellt.

 

Unter Windows 7 und 8,

 

wird der Ordner „<Systemlaufwerk >:\Benutzer\<Benutzername>\Desktop\Adobe Acrobat XI“ auf dem Desktop erstellt.

 

Um mit der Installation zu beginnen, öffnen Sie den Ordner „Adobe Acrobat XI“ und doppelklicken Sie auf die Datei „setup.exe“.

 

Wählen Sie im Dialogfeld zur Einrichtung von Adobe Acrobat XI eine Sprache aus und klicken Sie auf „OK“. Wählen Sie die Sprache des von Ihnen erworbenen Produkts aus. Klicken Sie im Bildschirm zur Einrichtung von Adobe Acrobat XI auf „Weiter“. Das Installationsprogramm berechnet den erforderlichen Speicherplatzbedarf und überprüft den Computer auf frühere Versionen. Wird eine frühere Version desselben Acrobat-Produkts gefunden, deinstallieren Sie diese durch Klicken auf „Weiter“.

 

4. Der Bildschirm zur Einrichtung wird geöffnet. Geben Sie dort Ihren Namen, Ihr Unternehmen und die Seriennummer ein. Wenn Sie das Produkt als Testversion verwenden oder ein Abonnement erworben haben (nur Pro), muss keine Seriennummer eingegeben werden. Bei Eingabe der Seriennummer muss der Computer mit dem Internet verbunden sein, da die Nummer online geprüft wird. Hinweis: Nach der Installation als Testversion können Sie die Software ab dem erstmaligen Starten 30 Tage lang nutzen.

 

5. Geben Sie die Seriennummer Ihrer Programmkopie ein. Die Seriennummer einzeln lizenzierter Produkte steht außen auf der DVD-Hülle. Wurde das Produkt als ESD (elektronische Softwareverteilung) im Adobe Store erworben, entnehmen Sie die Seriennummer der Seite, auf der der Kauf bestätigt wurde. Bei individuell lizenzierten EDS-Käufen wird die Seriennummer auch im Online-Bestellverlauf unter http://www.adobe.com vermerkt. Die Seriennummer bei über die Lizenzierungswebsite von Adobe getätigten Käufen steht im entsprechenden Datensatz unter http://licensing.adobe.com.

 

6. Klicken Sie im Bildschirm zur Aktivierung der Adobe-Lizenz auf „Weiter“. Die Aktivierung erfolgt anonym und automatisch durch die Software. Weitere Informationen zur Produktaktivierungsübertragung finden Sie auf der Website von Adobe unter http://www.adobe.com/go/activation_de/.

 

7. Wählen Sie einen Setuptyp aus:

  • Bei Auswahl von „Standard“ (Standardvorgabe) werden die Dateien für Acrobat, Acrobat Distiller, PDFMaker, der für Ihr System geeignete Adobe PostScript-Druckertreiber, Standardzusatzmodule und Zubehör installiert.
  • Bei Auswahl von „Vollständig“ werden alle Funktionen von Acrobat XI installiert. Für diesen Setuptyp wird das Maximum an Festplattenspeicher benötigt.
  • Bei „Angepasst“ können Sie die zu installierenden Komponenten bestimmen.

 

Hinweis: Eine Beschreibung der einzelnen Komponenten erhalten Sie, indem Sie „Angepasst“ auswählen und auf „Weiter“ klicken. Rufen Sie die Beschreibung dann durch Auswahl der gewünschten Komponente auf. Wenn Sie keine angepasste Installation durchführen, sondern zum Bildschirm für die Auswahl des Setuptyps zurückkehren möchten, klicken Sie auf „Zurück“.

 

Klicken Sie auf „Weiter“. Ändern Sie das Installationsverzeichnis oder übernehmen Sie das angegebene Standardverzeichnis und klicken Sie auf „Weiter“.

 

8. Klicken Sie auf „Installieren“. Die Installation beginnt. Sollten Prozesse ausgeführt werden, die mit der Installation in Konflikt stehen, werden Sie vom Installationsprogramm aufgefordert, diese anzuhalten. Erst dann kann mit der Installation fortgefahren werden. Beenden Sie den Prozess und klicken Sie in das Installationsprogramm, um die Installation fortzusetzen.

 

9. Zuletzt wird das Dialogfeld „Installation beendet“ angezeigt. Klicken Sie auf „Fertigstellen“. Acrobat kann jetzt gestartet werden.

 

10. Akzeptieren Sie nach dem Starten die Endanwenderlizenzvereinbarung, damit Sie die Software auch verwenden können.

 

11. Wurde bei der Installation eine Seriennummer eingegeben, fahren Sie unten mit Schritt 12 fort. Wenn Sie Acrobat als Testversion oder als Abonnement (nur Pro) verwenden, wird der Bildschirm „Anmeldung erforderlich“ angezeigt. Wählen Sie dort die Option „Jetzt anmelden“ aus. Geben Sie im Bildschirm zum Anmelden Ihre Adobe-ID ein. Wenn Sie keine Adobe-ID haben, klicken Sie auf „Adobe-ID erstellen“ und geben Sie die erforderlichen Informationen ein. Klicken Sie anschließend auf „Erstellen“. Schließen Sie den Vorgang entsprechend den Bildschirmanweisungen ab. Klicken Sie auf „Anmelden“. Acrobat kann jetzt verwendet werden.

 

12. Wurde bei der Installation eine Seriennummer eingegeben, wird der Bildschirm zum Registrieren geöffnet. Geben Sie dort Ihre Adobe-ID ein. Wenn Sie keine Adobe-ID haben, klicken Sie auf „Adobe-ID erstellen“ und geben Sie die erforderlichen Informationen ein. Klicken Sie anschließend auf „Erstellen“. Schließen Sie den Vorgang zur Erstellung Ihrer Adobe-ID sowie den Registrierungsprozess entsprechend den Bildschirmanweisungen ab. Wahlweise können Sie auch auf „Überspringen“ klicken. WICHTIG: Zur Aktivierung der Software muss eine Verbindung mit dem Internet bestehen. Die Software muss innerhalb von 30 Tagen aktiviert werden. Nach Ablauf von 30 Tagen können Sie die Software nicht mehr verwenden.

 

So deinstallieren Sie Acrobat XI unter Windows

 

1. Deaktivieren Sie vor der Deinstallation von Acrobat XI das Produkt. Wählen Sie dazu „Hilfe > Deaktivieren…“ aus. Um mit der Deinstallation zu beginnen, öffnen Sie die Systemsteuerung und doppelklicken Sie auf „Software“.

 

2. Wählen Sie in der Liste den Eintrag „Acrobat XI“ aus und klicken Sie auf „Ändern/Entfernen“.

 

3. In einem Dialogfeld werden Sie aufgefordert, die Deinstallation von Acrobat zu bestätigen. Klicken Sie zur Deinstallation der Anwendung auf „Ja“.
