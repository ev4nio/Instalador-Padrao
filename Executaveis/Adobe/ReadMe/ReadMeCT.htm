Adobe® Acrobat® XI Pro 和 Standard 軟體

 

歡迎使用 Adobe Acrobat XI Pro 和 Adobe Acrobat XI Standard ReadMe，本文件包含有關 Adobe Acrobat 產品的重要資訊。適用於所有產品的 ReadMe 項目不會指定產品名稱。如需 Adobe Acrobat XI 產品支援資訊，請參閱 http://www.adobe.com/go/acrobat_support_tw。

 

系統需求

 

Acrobat XI Pro for Windows® 需求如下：

 

·         1.3 GHz 或更快的處理器

·         Microsoft® Windows XP SP3 (32 位元) 或 SP2 (64 位元)、Windows Server® 2003 R2 (32 位元和 64 位元)、Windows Server 2008 或 2008 R2 (32 位元和 64 位元)、Windows 7 (32 位元和 64 位元)、Windows 8 (32 位元和 64 位元)

·         512 MB 的已安裝 RAM (建議 1 GB)

·         1.9 GB 的可用硬碟空間 (注意：安裝程式會在安裝期間建立暫時資料夾，因此安裝時所需的實際硬碟空間會大於上述數值。)

·         1,024 x 768 螢幕解析度

·         Internet Explorer 7、8、9、10；Firefox (ESR)；Chrome

·         DVD-ROM 光碟機 (如果是從 DVD 安裝)

·         視訊硬體加速選購件

如果是 Windows Server 2003 SP2 以及 Windows XP SP2 (64 位元)，則需要 Microsoft Hot Fix KB-930627。請參閱：

http://support.microsoft.com/kb/930627。

 

 

Acrobat XI Standard for Windows® 需求如下：

 

·         1.3 GHz 或更快的處理器

·         Microsoft® Windows XP SP3 (32 位元) 或 SP2 (64 位元)、Windows Server® 2003 R2 (32 位元和 64 位元)、Windows Server 2008 或 2008 R2 (32 位元和 64 位元)、Windows 7 (32 位元和 64 位元)、Windows 8 (32 位元和 64 位元)

·         512 MB 的已安裝 RAM (建議 1 GB)

·         1.5 GB 的可用硬碟空間 (注意：安裝程式會在安裝期間建立暫時資料夾，因此安裝時所需的實際硬碟空間會大於上述數值。)

·         1,024 x 768 螢幕解析度

·         Internet Explorer 7、8、9、10；Firefox (延伸支援版本)；Chrome

·         DVD-ROM 光碟機 (如果是從 DVD 安裝)

·         視訊硬體加速選購件

如果是 Windows Server 2003 SP2 以及 Windows XP SP2 (64 位元)，則需要 Microsoft Hot Fix KB-930627。請參閱：

http://support.microsoft.com/kb/930627。

 

安裝說明

 

請使用以下指示來安裝新軟體或從先前的版本升級。如果要安裝升級，則可能需要提供所有權證明。

 

在 Windows 中安裝 Acrobat XI

 

1. 重新啟動 Windows，並關閉所有防毒軟體。

 

2. 將電腦連線至網際網路。

 

3. 開始安裝：

  • 如果您購買的 Acrobat 是以 DVD 方式提供，請插入 DVD。
  • 如果您購買的 Acrobat 是以下載內容方式提供，請將套件下載至硬碟中的某個位置。

 

Adobe 建議您在安裝軟體之前先備份所下載的套件，最好是備份至 DVD。按兩下 .exe 加以解壓縮時：

 

如果是 Windows XP 作業系統，

 

 <系統硬碟>:\Documents and Settings\<使用者>\Desktop\Adobe Acrobat XI 檔案夾會建立在桌面上。

 

如果是 Windows 7 和 8 作業系統，

 

<系統硬碟>:\users\<使用者名稱>\Desktop\Adobe Acrobat XI 檔案夾會建立在桌面上。

 

準備好安裝時，請開啟 Adobe Acrobat XI 檔案夾，並按兩下 setup.exe。

 

在「Adobe Acrobat XI 安裝程式」對話方塊中，選取語言並按一下「確認」。請務必選取您所購買的語言。在「Adobe Acrobat XI 安裝程式」畫面中按「下一步」。安裝程式會計算磁碟空間需求，並檢查是否有先前版本。如果找到相同 Acrobat 產品的先前版本，請按「繼續」加以解除安裝。

 

4. 設定畫面會要求您輸入姓名、組織和序號。如果您使用試用版產品，或者已購買訂閱 (僅限 Pro)，則不需要輸入序號。如果要輸入序號，請確定電腦已連線至網際網路，因為會在線上完成序號驗證。備註：安裝試用版可讓您試用該軟體 30 天 (從首次啟動軟體起開始計算)。

 

5. 輸入您的程式版本序號。序號位於 DVD 包裝盒外部；如果是透過 Adobe Store 購買，則序號位於 ESD (電子軟體傳送) 的收據頁面上。您也可以在 http://www.adobe.com/tw/ 的線上訂購記錄中，找到每筆授權之 ESD 購買項目的序號。如果是透過 Adobe 授權網站購買，則可以在 http://licensing.adobe.com 的記錄中取得序號。

 

6. 在「Adobe 授權啟動」畫面中按「下一步」。「啟動」是一連串由軟體完成之簡單且快速的匿名步驟。如需更多有關產品啟動的資訊，請造訪 Adobe 網站：http://www.adobe.com/go/activation_tw。

 

7. 選取安裝類型：

  • 「典型」(預設為典型) 會安裝 Acrobat、Acrobat Distiller、PDFMaker、適用於您系統的 Adobe PostScript 印表機驅動程式、標準外掛程式以及配件等程式檔案。
  • 「完整」會安裝所有 Acrobat XI 功能，且需要最多的硬碟空間。
  • 「自訂」可讓您指定要安裝的元件。

 

備註：如需元件的說明，請選取「自訂」並按「下一步」。然後選取元件來檢視其說明。如果您不想要繼續進行自訂安裝，請按「上一步」以返回選取安裝類型。

 

按「下一步」。變更安裝目錄 (如有需要)，否則會使用畫面所顯示的預設目錄，然後按「下一步」。

 

8. 按一下「安裝」，便會繼續安裝。如果有其他程序與安裝程序發生衝突，則安裝程式會提示您先停止這些程序再繼續安裝。關閉這些程序，然後按一下安裝程式以繼續安裝。

 

9. 最後一個對話方塊是「設定已完成」。按一下「結束」，就可以立即啟動 Acrobat。

 

10. 啟動時，請接受終端使用者授權協議以允許您使用軟體。

 

11. 如果您已在安裝期間輸入序號，請查看下方的步驟 12。如果是使用 Acrobat 試用版或 Acrobat 訂閱 (僅限 Pro)，便會顯示「需要登入」畫面。請在「需要登入」畫面上選取「立即登入」。在「登入」畫面中輸入您的 Adobe ID 認證。如果您沒有 Adobe ID，請按一下「建立 Adobe ID」，並提供所需的詳細資料。接著按一下「建立」，並遵循畫面上的說明完成建立程序。按一下「登入」，您就可以立即使用 Acrobat 了。

 

12. 如果您已安裝期間輸入序號，便會顯示「註冊」畫面。在「註冊」畫面中輸入您的 Adobe ID 認證。如果您沒有 Adobe ID，請按一下「建立 Adobe ID」，並提供所需的詳細資料。接著按一下「建立」，並遵循畫面上的說明完成 Adobe ID 建立和註冊程序。您也可以選擇按下「略過」。注意事項：您必須連線至網際網路才能啟動軟體。必須在 30 天之內啟動您的軟體。30 天之後，軟體將無法運作。

 

在 Windows 中解除安裝 Acrobat XI

 

1. 解除安裝 Acrobat XI 之前，請先停用該產品。若要停用，請先選取「說明 > 停用...」。接著，若要解除安裝，請啟動「控制台」，並從中選取「新增或移除程式」。

 

2. 從顯示的應用程式清單中，反白選取 Acrobat XI 並按「移除/解除安裝」按鈕。

 

3. 此時會顯示一個對話方塊，詢問是否確定要移除 Acrobat。選擇「是」即可解除安裝該產品。

註冊

 

啟動 Acrobat 時，Acrobat 將提示您登入並註冊軟體。您必須註冊才能獲得技術支援。
