Adobe® Acrobat® XI Pro 和 Standard 软件

 

欢迎阅读 Adobe® Acrobat® XI Pro 和 Adobe Acrobat XI Standard 自述文件，本自述介绍了 Adobe Acrobat 产品的基本信息。适用于所有产品的自述内容不指定产品名称。有关 Adobe Acrobat XI 产品的支持信息，请参阅 http://www.adobe.com/go/acrobat_support_cn。

 

系统要求

 

Acrobat XI Pro for Windows® 的系统要求如下：

 

·         1.3 千兆赫或更快的处理器

·         Microsoft® Windows XP with SP3（32 位）（或 SP2（64 位））；Windows Server® 2003 R2（32 位和 64 位）；Windows Server 2008 或 2008 R2（32 位和 64 位）；Windows 7（32 位和 64 位）；Windows 8（32 位和 64 位）

·         512 MB 已安装 RAM（推荐 1 GB）

·         1.9 GB 可用硬盘空间（注意：安装程序在安装过程中会生成临时文件，因此安装时所需的实际硬盘空间大于此值。）

·         1,024 x 768 屏幕分辨率

·         Internet Explorer 7、8、9、10；Firefox (ESR)；Chrome

·         DVD-ROM 驱动器（如果从 DVD 安装）

·         视频硬件加速（可选）

对于 Windows Server 2003 SP2 和 Windows XP SP2（64 位)，需要安装 Microsoft 修补程序 KB-930627。请参阅：

http://support.microsoft.com/kb/930627

 

 

Acrobat XI Standard for Windows® 的系统要求如下：

 

·         1.3 千兆赫或更快的处理器

·         Microsoft® Windows XP with SP3（32 位）（或 SP2（64 位））；Windows Server® 2003 R2（32 位和 64 位）；Windows Server 2008 或 2008 R2（32 位和 64 位）；Windows 7（32 位和 64 位）；Windows 8（32 位和 64 位）

·         512 MB 已安装 RAM（推荐 1 GB）

·         1.5 GB 可用硬盘空间（注意：安装程序在安装过程中会生成临时文件，因此安装时所需的实际硬盘空间大于此值。）

·         1,024 x 768 屏幕分辨率

·         Internet Explorer 7、8、9、10；Firefox（长期支持版）；Chrome

·         DVD-ROM 驱动器（如果从 DVD 安装）

·         视频硬件加速（可选）

对于 Windows Server 2003 SP2 和 Windows XP SP2（64 位)，需要安装 Microsoft 修补程序 KB-930627。请参阅：

http://support.microsoft.com/kb/930627

 

安装说明

 

请按照以下说明安装新软件或从旧版本进行升级。如果您安装的是升级，则需要提供所有权证明。

 

在 Windows 中安装 Acrobat XI

 

1. 重启 Windows 并关闭所有防病毒软件。

 

2. 将计算机连接至 Internet。

 

3. 开始安装：

  • 如果您购买的是 DVD 版 Acrobat，请插入 DVD。
  • 如果您购买的是下载版 Acrobat，请将软件包下载至硬盘驱动器上的某个位置。

 

Adobe 建议您在安装软件前备份下载的软件包，最好是备份至 DVD。双击 .exe 进行解压缩时：

 

对于 Windows XP 操作系统，

 

将在桌面上创建 <系统驱动器>:\Documents and Settings\<用户>\Desktop\Adobe Acrobat XI 文件夹。

 

对于 Windows 7 和 Windows 8 操作系统，

 

将在桌面上创建 <系统驱动器>:\users\<用户名>\Desktop\Adobe Acrobat XI 文件夹。

 

可以安装时，打开 Adobe Acrobat XI 文件夹并双击 setup.exe。

 

在“Adobe Acrobat XI 设置”对话框中，选择一种语言，然后单击“确定”。请确保选择的是您购买的语言。在“Adobe Acrobat XI 设置”屏幕中单击“下一步”。安装程序会计算磁盘空间要求并检查是否安装了旧版本。如果找到了同一 Acrobat 产品的旧版本，请按“继续”以卸载该版本。

 

4. 设置屏幕要求您输入姓名、组织和序列号。如果您使用的是本产品的试用模式或已购买订阅（仅适用于 Pro），则无需输入序列号。输入序列号时，请确保您的计算机已连接至 Internet，以便完成联机序列号验证。注意：以试用模式安装时，您可以试用本软件 30 天（从第一次启动起算）。

 

5. 为您的程序输入序列号。购买时获单独许可的序列号位于 DVD 包装盒的外包装上，在 Adobe Store 上通过 ESD（电子软件交付）购买的序列号在收货页面上。对于通过 ESD 购买且已获单独许可的序列号，也可以在 http://www.adobe.com/cn 上的网上订单历史记录中找到。通过 Adobe 授权网站购买的序列号可在 http://licensing.adobe.com 下您的记录中找到。

 

6. 在“Adobe 许可证激活”屏幕中单击“下一步”。激活是软件所完成的一系列匿名的、简单快捷的步骤。有关产品激活的更多信息，请访问 Adobe 网站：http://www.adobe.com/go/activatio_cn

 

7. 选择一种安装类型：

  • “典型”（默认为典型）将安装 Acrobat、Acrobat Distiller、PDFMaker，符合您系统的 Adobe PostScript 打印机驱动程序，标准增效工具和附属程序。
  • “完全”将安装所有 Acrobat XI 功能，需要的磁盘空间最大。
  • “自定义”可以指定要安装的组件。

 

注意：有关组件的描述，请选择“自定义”，然后单击“下一步”。然后选择一个组件来查看其描述。如果不要继续自定义安装，单击“上一步”返回以重新选择安装类型。

 

单击“下一步”。更改安装目录（如果需要），否则将显示默认目录，然后单击“下一步”。

 

8. 单击“安装”开始进行安装。如果有其它正在运行的进程与安装冲突，安装程序将提示您先终止这些进程，然后才能继续安装。关闭该进程并在安装程序中单击以继续安装。

 

9. 最后一个对话框是“安装完成”。单击“完成”，现在即可启动 Acrobat。

 

10. 启动时，请接受最终用户许可协议以便使用软件。

 

11. 如果您在安装期间输入了序列号，请参见下述步骤 12。如果您使用的是 Acrobat 试用模式或 Acrobat 订阅（仅适用于 Pro 版本），将显示“需要登录”屏幕。在“需要登录”屏幕上选择“立即登录”。在“登录”屏幕上，输入您的 Adobe ID 凭据。如果您没有 Adobe ID，请单击“创建 Adobe ID”，并提供所需的详细信息。然后单击“创建”。根据屏幕上的说明来完成创建过程。单击“登录”。现在即可使用 Acrobat。

 

12. 如果您在安装期间输入了序列号，将显示“注册”屏幕。在“注册”屏幕上，输入您 Adobe ID 凭据。如果您没有 Adobe ID，请单击“创建 Adobe ID”，并提供所需的详细信息。然后单击“创建”。根据屏幕上的说明来完成 Adobe ID 创建和注册过程。您可以视情况按“跳过”。重要信息：您必须连接至 Internet 以激活软件。您必须在 30 天内激活该软件。30 天后本软件将无法运行。

 

从 Windows 中卸载 Acrobat

 

1. 在卸载 Acrobat XI 之前，请先取消激活产品。要执行此项操作，请选择“帮助”>“取消激活...”。然后，启动“控制面板”并从中选择“添加或删除程序”以卸载。

 

2. 从显示的应用程序列表中，将 Acrobat XI 高亮显示并按“删除/卸载”按钮。

 

3. 将显示一个对话框，询问您是否确认删除 Acrobat。选择“是”卸载该产品。

注册

 

当您启动 Acrobat时，Acrobat 将提示您登录并注册软件。注册后才能获得技术支持。
