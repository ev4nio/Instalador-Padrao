Adobe® Acrobat® XI Pro 및 Standard 소프트웨어

 

Adobe Acrobat 제품의 기본 정보가 포함된 Adobe® Acrobat® XI Pro 및 Adobe Acrobat XI Standard 읽어보기입니다. 모든 제품에 적용되는 읽어보기 항목은 제품 이름을 지정하지 않습니다. Adobe Acrobat XI 제품 지원 정보는 http://www.adobe.com/go/acrobat_support_kr를 참조하십시오.

 

시스템 요구 사항

 

Windows®용 Acrobat XI Pro에는 다음이 필요합니다.

 

·         1.3GHz 이상 프로세서

·         Microsoft® Windows XP SP3 32비트(SP2 64비트); Windows Server® 2003 R2(32비트 및 64비트); Windows Server 2008 또는 2008 R2(32비트 및 64비트); Windows 7(32비트 및 64비트); Windows 8(32비트 및 64비트)

·         512MB의 설치된 RAM(1GB 권장)

·         1.9GB의 사용 가능한 하드 디스크 공간(참고: 설치 프로그램에서 설치 중 임시 파일을 만들므로 이때 필요한 실제 하드 디스크 공간은 나열된 값보다 큽니다.)

·         1,024 x 768 화면 해상도

·         Internet Explorer 7, 8, 9, 10; Firefox (ESR); Chrome

·         DVD에서 설치하는 경우 DVD-ROM 드라이브

·         비디오 하드웨어 가속(선택 사항)

64비트용 Windows Server 2003 SP2 및 Windows XP SP2의 경우 Microsoft 핫픽스 KB-930627이 필요합니다. 참조:

http://support.microsoft.com/kb/930627

 

 

Windows®용 Acrobat XI Standard에는 다음이 필요합니다.

 

·         1.3GHz 이상 프로세서

·         Microsoft® Windows XP SP3 32비트(SP2 64비트); Windows Server® 2003 R2(32비트 및 64비트); Windows Server 2008 또는 2008 R2(32비트 및 64비트); Windows 7(32비트 및 64비트); Windows 8(32비트 및 64비트)

·         512MB의 설치된 RAM(1GB 권장)

·         1.5GB의 사용 가능한 하드 디스크 공간(참고: 설치 프로그램에서 설치 중 임시 파일을 만들므로 이때 필요한 실제 하드 디스크 공간은 나열된 값보다 큽니다.)

·         1,024 x 768 화면 해상도

·         Internet Explorer 7, 8, 9, 10; Firefox(확장 지원 릴리스); Chrome

·         DVD에서 설치하는 경우 DVD-ROM 드라이브

·         비디오 하드웨어 가속(선택 사항)

64비트용 Windows Server 2003 SP2 및 Windows XP SP2의 경우 Microsoft 핫픽스 KB-930627이 필요합니다. 참조:

http://support.microsoft.com/kb/930627

 

설치 지침

 

다음 지침을 사용하여 새 소프트웨어를 설치하거나 이전 버전에서 업그레이드합니다. 업그레이드를 설치하려는 경우 소유권 증명을 제공해야 할 수 있습니다.

 

Windows에서 Acrobat XI를 설치하려면

 

1. Windows를 다시 시작하고 모든 안티바이러스 소프트웨어를 끕니다.

 

2. 시스템을 인터넷에 연결합니다.

 

3. 설치를 시작합니다.

  • DVD로 Acrobat을 구매한 경우 DVD를 삽입합니다.
  • 다운로드로 Acrobat을 구매한 경우 패키지를 하드 디스크 드라이브의 위치에 다운로드합니다.

 

소프트웨어를 설치하기 전에 다운로드 패키지를 DVD에 백업하는 것이 좋습니다. .exe를 두 번 클릭하여 압축을 풀면

 

Windows XP 운영 체제의 경우

 

 <시스템 드라이브>:₩Documents and Settings₩<사용자>₩Desktop₩Adobe Acrobat XI 폴더가 바탕 화면에 만들어집니다.

 

Windows 7 및 8 운영 체제의 경우

 

<시스템 드라이브>:₩users₩<사용자 이름>₩Desktop₩Adobe Acrobat XI 폴더가 바탕 화면에 만들어집니다.

 

설치할 준비가 되면 Adobe Acrobat XI 폴더를 열고 setup.exe를 두 번 클릭합니다.

 

[Adobe Acrobat XI 설정] 대화 상자에서 언어를 선택하고 [확인]을 클릭합니다. 구매한 언어를 선택해야 합니다. [Adobe Acrobat XI 설정] 화면에서 [다음]을 클릭합니다. 설치 프로그램에서 디스크 공간 요구 사항을 계산하고 이전 버전을 확인합니다. 이전 버전의 동일한 Acrobat 제품을 찾은 경우 제거하려면 [계속]을 클릭합니다.

 

4. 설정 화면에서 이름, 조직 및 일련 번호를 입력할 것을 요청합니다. 평가판 모드로 제품을 사용 중이거나 구독(Pro에만 해당)을 구매한 경우에는 일련 번호를 입력할 필요가 없습니다. 일련 번호를 입력할 경우 온라인 일련 번호 유효성 검사가 수행되도록 시스템을 인터넷에 연결해야 합니다. 참고: 평가판 모드로 설치하면 처음 실행하는 날부터 30일 평가 기간 동안 소프트웨어를 사용할 수 있습니다.

 

5. 프로그램 사본의 일련 번호를 입력합니다. 개별적으로 라이센스된 구매 제품의 일련 번호는 DVD 케이스 바깥에 있으며, Adobe Store를 통한 ESD(Electronic Software Delivery) 구매의 경우에는 영수증 페이지에 있습니다. 개별적으로 라이센스된 ESD 구매 제품의 경우 http://www.adobe.com/kr의 온라인 주문 기록에서도 일련 번호를 찾을 수 있습니다. Adobe Licensing 웹 사이트를 통해 구매한 경우 일련 번호는 http://licensing.adobe.com의 기록에서 확인할 수 있습니다.

 

6. [Adobe 라이센스 활성화] 화면에서 [다음]을 클릭합니다. 활성화는 소프트웨어에 의해 완료되는 익명의 간단하고 빠른 일련의 단계입니다. 제품 활성화에 대한 자세한 내용은 다음 Adobe 웹 사이트를 방문하십시오. http://www.adobe.com/go/activation_kr

 

7. 설치 유형을 선택합니다.

  • [일반](기본값)에서는 Acrobat, Acrobat Distiller, PDFMaker, 시스템용 Adobe PostScript 프린터 드라이버, 표준 플러그인 및 보조 프로그램을 설치합니다.
  • [전체]에서는 모든 Acrobat XI 기능을 설치하고 가장 많은 디스크 공간이 필요합니다.
  • [사용자 정의]에서는 설치할 구성 요소를 지정할 수 있습니다.

 

참고: 구성 요소에 대한 설명은 [사용자 정의]를 선택하고 [다음]을 클릭합니다. 그런 다음 해당 설명을 볼 구성 요소를 선택합니다. 사용자 정의 설치를 계속하지 않으려는 경우 [뒤로]를 클릭하여 설치 유형 선택으로 돌아갑니다.

 

[다음]을 클릭합니다. 원하는 경우 설치 디렉토리를 변경하고 그렇지 않으면 기본 디렉토리가 표시되고 [다음]을 클릭합니다.

 

8. [설치]를 클릭하면 이제 설치가 진행됩니다. 설치와 충돌하는 프로세스가 실행 중인 경우 설치 프로그램에서 설치를 계속하기 전에 이러한 프로세스를 중지하라는 메시지를 표시합니다. 해당 프로세스를 닫고 설치 프로그램을 클릭하여 설치를 계속합니다.

 

9. 마지막 대화 상자는 [설치 완료]입니다. [마침]을 클릭하면 이제 Acrobat을 실행할 수 있습니다.

 

10. 실행 시 최종 사용자 사용권 계약에 동의해야 소프트웨어를 사용할 수 있습니다.

 

11. 설치 중 일련 번호를 입력한 경우 아래의 12단계를 참조하십시오. 평가판 모드 또는 구독(Pro만 해당)에서 Acrobat을 사용하는 경우 [로그인 필요] 화면이 나타납니다. [로그인 필요] 화면에서 [지금 로그인]을 선택합니다. [로그인] 화면에서 Adobe ID 자격 증명을 입력합니다. Adobe ID가 없는 경우 [Adobe ID 만들기]를 클릭하고 요청한 대로 세부 정보를 제공합니다. 그런 다음 [만들기]를 클릭합니다. 화면의 지침을 따라 만들기 프로세스를 완료합니다. [로그인]을 클릭합니다. 이제 Acrobat을 사용할 수 있습니다.

 

12. 설치 중 일련 번호를 입력한 경우 [등록] 화면이 표시됩니다. [등록] 화면에서 Adobe ID 자격 증명을 입력합니다. Adobe ID가 없는 경우 [Adobe ID 만들기]를 클릭하고 요청한 대로 세부 정보를 제공합니다. 그런 다음 [만들기]를 클릭합니다. 화면의 지침을 따라 Adobe ID 만들기 및 등록 프로세스를 완료합니다. 선택적으로 [건너뛰기]를 누를 수 있습니다. 중요: 소프트웨어 사본을 활성화하려면 인터넷에 연결되어야 합니다. 사본은 30일 이내에 활성화해야 합니다. 30일 후에는 소프트웨어 작동이 중지됩니다.

 

Windows에서 Acrobat XI를 제거하려면

 

1. Acrobat XI를 제거하기 전에 제품을 비활성화해야 합니다. 이렇게 하려면 [도움말] > [비활성화…]를 선택합니다. 그런 다음 제거하려면 [제어판]을 실행하고 [프로그램 추가 또는 제거]를 선택합니다.

 

2. 표시되는 응용 프로그램 목록에서 Acrobat XI를 강조 표시하고 [제거/설치 제거] 단추를 누릅니다.

 

3. Acrobat을 제거할 것인지 확인을 요청하는 대화 상자가 나타납니다. [예]를 선택하여 제품을 제거합니다.

등록

 

Acrobat을 시작하면 Acrobat에서 로그인하고 소프트웨어를 등록하라는 메시지를 표시합니다. 기술 지원을 받으려면 등록해야 합니다.
