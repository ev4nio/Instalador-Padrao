Requisitos do sistema

 

O Acrobat XI Pro para Windows® requer os seguintes itens:

 

•         Processador de 1,3 Gigahertz ou mais rápido

•         Microsoft® Windows XP com SP3 para 32 bits (com SP2 para 64 bits); Windows Server® 2003 R2 (32 bits e 64 bits); Windows Server 2008 ou 2008 R2 (32 bits e 64 bits); Windows 7 (32 bits e 64 bits); Windows 8 (32 bits e 64 bits)

•         512 MB de memória RAM instalada (1 GB recomendado)

•         1,9 GB de espaço disponível no disco rígido (Observação: o instalador cria arquivos temporários durante a instalação, portanto o espaço de disco rígido exigido deve ser maior do que o valor listado.)

•         1024 x 768 de resolução da tela

•         Internet Explorer 7, 8, 9, 10; Firefox (ESR); Chrome

•         DVD-ROM se instalado de um DVD

•         Hardware de aceleração de vídeo é opcional

Para Windows Server 2003 SP2 e Windows XP SP2 e para 64-bits, é necessário Microsoft Hot Fix KB-930627. Consulte:

http://support.microsoft.com/kb/930627

 

 

O Acrobat XI Standard para Windows® requer os seguintes itens:

 

•         Processador de 1,3 Gigahertz ou mais rápido

•         Microsoft® Windows XP com SP3 para 32 bits (com SP2 para 64 bits); Windows Server® 2003 R2 (32 bits e 64 bits); Windows Server 2008 ou 2008 R2 (32 bits e 64 bits); Windows 7 (32 bits e 64 bits); Windows 8 (32 bits e 64 bits)

•         512 MB de memória RAM instalada (1 GB recomendado)

•         1,5 GB de espaço disponível no disco rígido (Observação: o instalador cria arquivos temporários durante a instalação, portanto o espaço de disco rígido exigido deve ser maior do que o valor listado.)

•         1024 x 768 de resolução da tela

•         Internet Explorer 7, 8, 9, 10; Firefox (Extended Support Release); Chrome

•         DVD-ROM se instalando de um DVD

•         Hardware de aceleração de vídeo é opcional

Para Windows Server 2003 SP2 e Windows XP SP2 e para 64 bits, é necessário Microsoft Hot Fix KB-930627. Consulte:

http://support.microsoft.com/kb/930627

 

Instruções de instalação

 

Use as instruções a seguir para instalar um novo software ou fazer atualização de uma versão anterior. Se estiver instalando uma atualização, poderá ser necessário oferecer provas de propriedade.

 

Para instalar o Acrobat XI no Windows

 

1. Reinicie o Windows e desative qualquer software antivírus.

 

2. Conecte a máquina à internet.

 

3. Inicie a instalação:

  • Se tiver adquirido o Acrobat em um DVD, insira o DVD.
  • Se tiver adquirido o Acrobat por download, faça o download do pacote para um local em seu disco rígido.

 

A Adobe recomenda que você faça um backup do pacote baixado, preferivelmente em um DVD antes de instalar o software. Clique duas vezes no .exe para descompactar:

 

Em sistemas operacionais Windows XP,

 

<unidade do sistema >:\Documents and Settings\<usuário>\Área de trabalho\a pasta Adobe Acrobat XI é criada na área de trabalho.

 

Em sistemas operacionais Windows 7 e 8,

 

< unidade do sistema >:\usuários\<nome de usuário>\Área de Trabalho\a pasta Adobe Acrobat XI é criada na área de trabalho.

 

Quando estiver pronto para instalar, abra a pasta Adobe Acrobat XI e clique duas vezes em setup.exe

 

Na caixa de diálogo de instalação do Adobe Acrobat XI, selecione um idioma e clique em “OK”. Certifique-se de selecionar o idioma que você adquiriu. Clique em “Avançar” na tela de instalação do Adobe Acrobat XI. O instalador computa os requisitos de espaço em disco e verifica se há versões anteriores. Se uma versão anterior do mesmo produto Acrobat for encontrada, pressione Continuar para desinstalá-la.

 

4. A tela de instalação solicita que você insira seu nome, organização e número de série. Se estiver utilizando um produto no modo de avaliação ou adquiriu uma assinatura, (somente Pro) não será preciso inserir um número de série. Se for inserir um número de série, certifique-se de que a máquina esteja conecta à internet já que será realizada a validação de número de série online. Observação: instalar no modo de avaliação permite que você use o software por um período de avaliação de 30 dias a partir do primeiro uso.

 

5. Insira o número de série da sua cópia do programa. O número de série de compras licenciadas individualmente está localizado na parte de fora da capa do DVD ou na página de recibo das compras ESD (entrega eletrônica de software) feitas pela Adobe Store. Você também pode localizar os números de série de compras ESD licenciadas individualmente no seu histórico de pedidos online em http://www.adobe.com. O número de série das compras feitas pelo site Adobe Licensing está disponível em seus registros em http://licensing.adobe.com.

 

6. Clique em “Avançar” na tela de Ativação de licença Adobe. Ativação é uma série anônima de etapas simples e rápidas concluídas pelo software. Para obter mais informações sobre ativação de produtos, visite o site da Adobe em: http://www.adobe.com/go/activation_br/

 

7. Selecione um tipo de instalação:

  • A Típica (o padrão é Típica) instala os arquivos de programa do Acrobat, Acrobat Distiller, PDFMaker, o driver de impressora Adobe PostScript para seu sistema, plugins e acessórios padrão.
  • Instala totalmente todos os recursos do Acrobat XI e precisa de mais espaço em disco.
  • Personalizado permite especificar quais componentes deseja instalar.

 

Observação: para obter a descrição de um componente, selecione Personalizado e clique em Avançar. Selecione um componente para ver a descrição dele. Clique em Voltar para retornar para a seleção de um tipo de instalação se não desejar continuar com uma instalação personalizada.

 

Clique em “Avançar”. Altere o diretório de instalação (se desejar), se o diretório padrão estiver visível e clique em “Avançar”.

 

8. Clique em “Instalar” e a instalação prossegue. Se houver processos em execução que entrem em conflito com a instalação, o instalador solicitará que você pare esses processos antes de poder continuar a instalação. Feche o processos e clique no instalador para continuar a instalação.

 

9. O último diálogo é de “Instalação concluída”. Clique em “Concluir” e agora será possível iniciar o Acrobat.

 

10. Ao iniciar, aceite os termos e condições do contrato de licença do usuário para que possa usar o software.

 

11. Se você inseriu um número de série durante a instalação, veja a etapa 12 abaixo. Se estiver usando o Acrobat no modo de avaliação ou para uma assinatura (somente Pro), a tela Logon obrigatório aparecerá. Na tela Logon obrigatório selecione "Entrar agora" Na tela de acesso, insira as credenciais de sua Adobe ID. Se não possuir uma Adobe ID, clique em “Criar uma Adobe ID” e forneça os detalhes solicitados. Em seguida, clique em Criar. Siga as instruções na tela para concluir o processo de criação. Clique em “Entrar”. O Acrobat agora poderá ser usado.

 

12. Se você inseriu um número de série durante a instalação, a tela de Registro aparecerá. Na tela de registro, insira as credenciais da Adobe ID. Se não possuir uma Adobe ID, clique em “Criar uma Adobe ID” e forneça os detalhes solicitados. Em seguida, clique em Criar. Siga as instruções na tela para concluir o processo de criação e registro da Adobe ID. Como opção, você pode pressionar “Ignorar”. IMPORTANTE: você deve estar conectado à internet para ativar sua cópia do software. Você tem 30 dias para ativar sua cópia. Após 30 dias o software deixará de funcionar.

 

Para desinstalar o Acrobat XI no Windows

 

1. Antes de desinstalar o Acrobat XI, Desative o produto. Para fazer isso, selecione Ajuda > Desativar… Em seguida, para desinstalar, inicie o Painel de Controle e, nele, selecione Adicionar ou Remover Programas.

 

2. Na lista de aplicativos exibida, selecione Acrobat XI e pressione o botão Remover/Desinstalar.

 

3. Uma caixa de diálogo aparece solicitando a confirmação de remoção do Acrobat. Escolha Sim para desinstalar o produto.

Registro

 

Ao iniciar o Acrobat, o Acrobat solicitará que você faça logon e registre seu software. Você deve registrar para receber o suporte técnico.
