Программное обеспечение Adobe® Acrobat® XI Pro и Standard

 

Ознакомьтесь с файлом ReadMe для Adobe® Acrobat® XI Pro и Adobe Acrobat XI Standard, который содержит важные сведения о продуктах Adobe Acrobat. Сведения в файле ReadMe, относящиеся ко всем продуктам, приводятся без указания названия конкретных продуктов. Сведения о поддержке продукта Adobe Acrobat XI см. на веб-сайте: http://www.adobe.com/go/acrobat_support_ru

 

Системные требования

 

Системные требования Acrobat XI Pro для ОС Windows®:

 

·         Процессор с частотой не менее 1,3 ГГц

·         Microsoft® Windows® XP с пакетом Service Pack 3 (32-разрядная) или Service Pack 2 (64-разрядная); Windows Server® 2003 R2 (32- и 64-разрядная); Windows Server 2008 или 2008 R2 (32- и 64-разрядная); Windows 7 (32- и 64-разрядная); Windows 8 (32- и 64-разрядная)

·         512 МБ свободной оперативной памяти (рекомендуется 1 ГБ)

·         1,9 ГБ доступного дискового пространства (примечание: программа установки создает временные файлы во время установки программного обеспечения, поэтому для выполнения установки требуется больше пространства на жестком диске.)

·         Разрешение монитора 1024x768

·         Internet Explorer 7, 8, 9 или 10; Firefox (ESR) или Chrome

·         Привод DVD-ROM (при установке программного обеспечения с DVD-диска)

·         Аппаратное ускорение видео (необязательно)

Для ОС Windows Server 2003 SP2 и Windows XP SP2 (64-разрядной) требуется оперативное исправление KB-930627. См.:

http://support.microsoft.com/kb/930627

 

 

Системные требования Acrobat XI Standard для ОС Windows®:

 

·         Процессор с частотой не менее 1,3 ГГц

·         Microsoft® Windows® XP с пакетом Service Pack 3 (32-разрядная) или Service Pack 2 (64-разрядная); Windows Server® 2003 R2 (32- и 64-разрядная); Windows Server 2008 или 2008 R2 (32- и 64-разрядная); Windows 7 (32- и 64-разрядная); Windows 8 (32- и 64-разрядная)

·         512 МБ свободной оперативной памяти (рекомендуется 1 ГБ)

·         1,55 ГБ доступного дискового пространства (примечание: программа установки создает временные файлы во время установки программного обеспечения, поэтому для выполнения установки требуется больше пространства на жестком диске).

·         Разрешение монитора 1024x768

·         Internet Explorer 7, 8, 9 или 10; Firefox Extended Support Release; Chrome

·         Привод DVD-ROM (при установке программного обеспечения с DVD-диска)

·         Аппаратное ускорение видео (необязательно)

Для ОС Windows Server 2003 SP2 и Windows XP SP2 (64-разрядной) требуется оперативное исправление KB-930627. См.:

http://support.microsoft.com/kb/930627

 

Инструкции по установке

 

Следуйте указанным ниже инструкциям, чтобы установить новую версию программного обеспечения или обновить предыдущую версию. При установке обновления вам может потребоваться подтвердить право на владение.

 

Установка Acrobat XI в ОС Windows

 

1. Перезагрузите ОС Windows и отключите все антивирусные программы.

 

2. Подключите компьютер к Интернету.

 

3. Запустите программу установки:

  • Если вы приобрели Acrobat на DVD-диске, вставьте DVD-диск.
  • Если вы приобрели Acrobat через Интернет, загрузите пакет в нужный каталог на жестком диске компьютера.

 

Adobe рекомендует перед установкой программного обеспечения создать резервную копию загруженного пакета (рекомендуется для этого использовать DVD-диск). После того как вы дважды щелкните файл .exe:

 

в операционных системах Windows XP

 

 будет создан каталог <системный диск>:\Documents and Settings\<пользователь>\Desktop\Adobe Acrobat XI.

 

в операционных системах Windows 7 и 8

 

будет создан каталог <системный диск>:\users\<имя пользователя>\Desktop\Adobe Acrobat XI.

 

Чтобы начать установку, откройте каталог Adobe Acrobat XI и дважды щелкните файл setup.exe

 

В диалоговом окне установки Adobe Acrobat XI выберите язык и нажмите ОК. Убедитесь, что выбран язык, соответствующий языковым настройкам приобретенной программы. Нажмите «Далее» на экране установки Adobe Acrobat XI. Программа установки вычисляет требования к дисковому пространству и проверяет наличие предыдущих версий. При обнаружении предыдущей версии аналогичного продукта Acrobat нажмите «Продолжить», чтобы удалить ее.

 

4. На экране установки потребуется ввести имя пользователя, название организации и серийный номер продукта. Если вы используете пробную версию продукта или приобрели продукт по подписке (только для версии Pro), то вводить серийный номер не требуется. При вводе серийного номера необходимо убедиться, что компьютер подключен к Интернету для выполнения проверки серийного номера через Интернет. Примечание: если вы устанавливаете пробную версию продукта, то вы можете использовать ее в течение ознакомительного периода (30 дней) с момента первого запуска.

 

5. Введите серийный номер продукта. Серийный номер продукта, на который предоставляется индивидуальная лицензия, указан на внешней стороне упаковки для DVD-диска либо на странице подтверждения заказа при приобретении продукта через Интернет на веб-сайте Adobe Store. Вы также можете просмотреть серийный номер продукта, приобретенного через Интернет, в истории ваших заказов на веб-сайте: http://www.adobe.com/ru. Серийный номер для продукта, приобретенного через веб-сайт лицензирования Adobe, указан в ваших персональных данных по адресу: http://licensing.adobe.com.

 

6. Нажмите «Далее» на экране активации лицензии Adobe. Процедура активации включает несколько простых коротких анонимных операций, выполняемых программным обеспечением. Для получения дополнительных сведений об активации продукта посетите веб-сайт Adobe по адресу: http://www.adobe.com/go/activation_ru/

 

7. Выберите тип установки:

  • «Обычная» (выбрано по умолчанию) — установка файлов программ Acrobat, Acrobat Distiller, PDFMaker, драйвера принтера Adobe PostScript, а также стандартных подключаемых модулей и дополнительных функций.
  • «Полная» — установка всех инструментов Acrobat XI (требуется наибольшее дисковое пространство).
  • «Пользовательская» — установка только выбранных компонентов.

 

Примечание: чтобы просмотреть описание компонента, выберите «Пользовательская», затем нажмите Далее. После этого выберите компонент, чтобы просмотреть его описание. Нажмите «Назад», чтобы вернуться к выбору типа установки (если выполнять пользовательскую установку не требуется).

 

Щелкните «Далее». При необходимости измените каталог установки либо оставьте каталог по умолчанию без изменений, затем нажмите «Далее».

 

8. Нажмите «Установить», чтобы начать процедуру установки. Если некоторые процессы препятствуют установке программного обеспечения, то программа установки предложит оставить эти процессы для продолжения установки. Закройте соответствующие процессы и щелкните окно программы установки, чтобы продолжить процедуру.

 

9. Последнее диалоговое окно установки: «Установка завершена». Нажмите «Готово»; после этого можно запустить Acrobat.

 

10. При первом запуске необходимо принять лицензионное соглашение с конечным пользователем; это необходимо для использования программного обеспечения.

 

11. Если во время установки вы указали серийный номер, то перейдите к шагу 12 внизу. При использовании пробной версии Acrobat или версии по подписке (только для программы Pro) появится экран «Требуется выполнить вход». На экране «Требуется выполнить вход» выберите «Войти сейчас». На экране входа в учетную запись введите учетные данные идентификатора Adobe. Если у вас нет идентификатора Adobe, нажмите «Создать идентификатор Adobe», затем укажите необходимые данные. После этого нажмите «Создать». Следуйте инструкциям на экране, чтобы завершить процедуру создания учетной записи. Щелкните «Войти». Теперь вы можете использовать программу Acrobat.

 

12. Если вы ввели серийный номер во время установки, то появится экран «Регистрация». На экране регистрации учетной записи введите учетные данные идентификатора Adobe. Если у вас нет идентификатора Adobe, нажмите «Создать идентификатор Adobe», затем укажите необходимые данные. После этого нажмите «Создать». Следуйте инструкциям на экране, чтобы создать идентификатор Adobe и завершить процедуру регистрации. При необходимости можно также нажать «Пропустить». ВАЖНО: Для активации программного обеспечения требуется подключение к Интернету. Активацию необходимо выполнить в течение 30 дней после установки. По истечении 30 дней с момента установки программа перестает функционировать.

 

Удаление Acrobat XI в ОС Windows

 

1. Перед удалением Acrobat XI необходимо деактивировать продукт. Для этого выберите «Справка» > «Деактивация...» Затем откройте «Панель управления» и выберите «Установка и удаление программ».

 

2. В появившемся списке приложений выберите Acrobat XI и нажмите кнопку «Удалить».

 

3. Появится диалоговое окно с требованием о подтверждении удаления. Выберите «Да», чтобы удалить продукт.
