Adobe® Acrobat® XI Pro e Standard

 

Questo documento Leggimi di Adobe® Acrobat® XI Pro e Adobe Acrobat XI Standard contiene informazioni importanti sui prodotti Adobe Acrobat. Per i file Leggimi applicabili a tutti i prodotti non viene specificato il nome del prodotto. Per informazioni relative all'assistenza prodotto per Adobe Acrobat XI, visitare http://www.adobe.com/go/acrobat_support_it

 

Requisiti di sistema

 

Requisiti per :Acrobat XI Pro per Windows®

 

•         Processore da almeno 1,3 GHz

•         Microsoft® Windows XP con SP3 per 32 bit (con SP2 per 64 bit); Windows Server® 2003 R2 (32 bit e 64 bit); Windows Server 2008 o 2008 R2 (32 bit e 64 bit); Windows 7 (32 bit e 64 bit); Windows 8 (32 bit e 64 bit)

•         512 MB di RAM installata (consigliato: 1 GB)

•         1,9 GB di spazio disponibile su disco (nota: durante l'installazione vengono creati dei file temporanei, pertanto lo spazio su disco richiesto inizialmente è maggiore del valore qui riportato)

•         Risoluzione schermo 1024x768

•         Internet Explorer 7, 8, 9, 10; Firefox (ESR); Chrome

•         Unità DVD-ROM, nel caso di installazione da DVD

•         Accelerazione hardware per video (facoltativa)

Per Windows Server 2003 SP2 e Windows XP SP2 per 64 bit, è richiesto Microsoft Hot Fix KB-930627. Visitare:

http://support.microsoft.com/kb/930627

Istruzioni di installazione

 

Per installare un nuovo software o aggiornare una precedente versione, seguire la procedura di seguito. Per installare un aggiornamento, potrebbe venire richiesta una prova di proprietà della versione precedente.

 

Per installare Acrobat XI su Windows

 

1. Riavviare Windows e disattivare eventuale software antivirus.

 

2. Collegare il computer a Internet.

 

3. Avviare l’installazione:

  • Se Acrobat è stato acquistato su DVD, inserire il DVD.
  • Se Acrobat è stato acquistato come download, scaricare il pachetto sul proprio disco rigido.

 

Prima di installare il software, si consiglia di effettuare il backup del pacchetto scaricato, preferibilmente su un DVD. Quando si fa doppio clic sul file .exe per decomprimerlo:

 

Su Windows XP,

 

<viene creata sul desktop la cartella unità di sistema>:\Documents and Settings\<utente>\Desktop\Adobe Acrobat XI.

 

Per sistemi operativi Windows 7 e 8,

 

viene creata sul desktop la cartella <unità di sistema>:\utenti\<nome utente>\Desktop\Adobe Acrobat XI.

 

Quando si è pronti per l’installazione, aprire la cartella Adobe Acrobat XI e fare doppio clic su setup.exe

 

Nella finestra di dialogo per l’isntallazione di Adobe Acrobat XI, selezionare una lingua e fare clic su OK. Accertarsi di selezionare la lingua che corrisponde alla versione acquistata. Nella schermata di installazione di Adobe Acrobat XI fare clic su Avanti. Il programma di installazione calcola i requisiti di spazio e verifica la presenza di versioni precedenti. Se viene trovata una versione precedente dello stesso prodotto Acrobat, fare clic su Continua per disinstallarla.

 

4. Nella schermata di installazione viene richiesto di inserire nome, società e numero di serie. Per utilizzare il prodotto in modalità di prova gratuita o se è stata acquistata un’iscrizione (solo Pro), non è necessario inserire il numero di serie. Se si inserisce un numero di serie, accertarsi che sia disponibile una connessione a Internet affinché il numero di serie possa essere convalidato online. Nota: se si installa il software come versione di prova, sarà possibile utilizzarlo per 30 giorni a partire dal primo avvio.

 

5. Immettere il numero di serie della propria copia del programma. Il numero di serie dei prodotti acquistati singolarmente si trova sul lato esterno della custodia del DVD oppure nella pagina di ricevuta nel caso di acquisti ESD effettuati da Adobe Store con cosegna elettronica del software. Per gli acquisti di licenze singole ESD, il numero di serie si trova inoltre nella cronologia degli ordini disponibile online su http://www.adobe.com. Il numero di serie per acquisti effettuati tramite Adobe Licensing Website è disponibile nel record corrispondente su http://licensing.adobe.com.

 

6. Nella schermata di attivazione della licenza Adobe fare clic su Avanti. L’attivazione prevede l'esecuzione da parte del software di una serie di operazioni anomine, rapide e semplici. Per ulteriori informazioni sull'attivazione dei prodotti, visitare http://www.adobe.com/go/activation_it/

 

7. Selezionare il tipo di installazione:

  • L’installazione predefinita è Tipica e comporta l’installazione dei file di programma per Acrobat, Acrobat Distiller, PDFMaker, il driver di stampa Adobe PostScript per il sistema in uso, i plug-in standard e altri accessori.
  • La modalità di installazione Completa installa tutte le caratteristiche di Acrobat XI e richiede maggiore spazio su disco.
  • La modalità Personale consente di specificare i compomenti da installare.

 

Nota: per una descrizione di un componente, selezionare Personale e fare clic su Avanti. Quindi selezionare un componente per vederne la descrizione. se non si desidera procedere con l’installazione personale, fare clic su Indietro per tornare alla selezione del tipo di installazione.

 

Fare clic su Avanti. Se necessario modificare la directory di installazione oppure mantenere la directory predefinita visualizzata, quindi fare clic su Avanti.

 

8. Fare clic su Installa per avviare l’installazione. Se sono in esecuzione dei processi in conflitto con l’installazione, il programma di installazione richiede di interromperli prima di procedere. Chiudere il processo in questione e fare clic sul programma di installazione per riprendere l’installazione.

 

9. L’ultima finestra di dialogo visualizzata è quella del completamento dell’installazione. Fare clic su Fine, dopodiché è possibile avviare Acrobat.

 

10. All’avvio, per poter utilizzare il software è necessario accettare il Contratto di licenza perl’utente finale.

 

11. Se durante l’installazione è stato inserito un numero di serie, vedere il passaggio 12 di seguito. Se si utilizza Acrobat in modalità di prova o con un’iscrizione (solo Pro), viene visualizzata la schermata Sign In Required (Accesso richiesto). Nella schermata Sign In Required (Accesso richiesto), selezionare “Sign in now” (Accedi ora). Nella schermata di accesso, immettere le credenziali del proprio ID Adobe. Se non si dispone di un ID Adobe, fare clic su “Create un ID Adobe” e fornire i dati richiesti. Quindi fare clic su Crea. Seguire le istruzioni visualizzate per completare la procedura. Fare clic su Accedi. Acrobat può ora essere utilizzato.

 

12. Se durante l’installazione è stato inserito un numero di serie, viene visualizzata la schermata di registrazione. Nella schermata di registrazione, immettere le credenziali del proprio ID Adobe. Se non si dispone di un ID Adobe, fare clic su “Create un ID Adobe” e fornire i dati richiesti. Quindi fare clic su Crea. Seguire le istruzioni visualizzate per completare la procedura. È possibile fare clic su “Skip” (Ignora). IMPORTANTE: per attivare la propria copia del software è necessaria una connessione Internet. L’attivazione deve essere eseguita entro 30 giorni. Trascorsi 30 giorni, il software cesserà di funzionare.

 

Per disinstallare Acrobat XI su Windows

 

1. Prima di disintallare Acrobat XI è necessario disattivare il prodotto. Per disattivarlo, scegliere ? > Disattiva... Quindi, per disinstallarlo, avviare il Pannello di controllo e scegliere Installazione applicazioni.

 

2. Nell’elenco delle applicazioni, evidenziare Acrobat XI e fare clic sul pulsnate Rimuovi/Disinstalla.

 

3. Viene visualizzata una finestra di dialogo per confermare la rimozione di Acrobat. Fare clic su Sì per disinstallare il prodotto.
