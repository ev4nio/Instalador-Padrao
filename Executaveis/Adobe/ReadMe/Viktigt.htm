Adobe® Acrobat® XI Pro och Standard

 

Välkommen till Viktigt om Adobe® Acrobat® XI Pro och Adobe Acrobat XI Standard. Den här filen innehåller viktig information om Adobe Acrobat-produkter. De avsnitt i filen som rör alla produkter anger inget produktnamn. Du hittar supportinformation om Adobe Acrobat XI på http://www.adobe.com/go/acrobat_support_se

 

Systemkrav

 

Acrobat XI Pro för Windows® kräver följande:

 

•         1,3 GHz eller snabbare processor

•         Microsoft® Windows XP med SP3 för 32-bitars (med SP2 för 64-bitars); Windows Server® 2003 R2 (32- och 64-bitars); Windows Server 2008 eller 2008 R2 (32- och 64-bitars); Windows 7 (32- och 64-bitars); Windows 8 (32- och 64-bitars)

•         512 MB installerat RAM-minne (1 GB rekommenderas)

•         1,9 GB ledigt hårddiskutrymme (Obs! Under installationen skapas tillfälliga filer, och det krävs då mer ledigt hårddiskutrymme än vad som anges här.)

•         En skärmupplösning på 1 024 x 768

•         Internet Explorer 7, 8, 9, 10; Firefox (ESR); Chrome

•         DVD-ROM-enhet, vid installation från dvd-skiva

•         Maskinvaruacceleration för video är valfritt

För Windows Server 2003 SP2 och Windows XP SP2 för 64-bitars krävs Microsoft Hot Fix KB-930627. Se:

http://support.microsoft.com/kb/930627

 

 

Acrobat XI Standard för Windows® kräver följande:

 

•         1,3 GHz eller snabbare processor

•         Microsoft® Windows XP med SP3 för 32-bitars (med SP2 för 64-bitars); Windows Server® 2003 R2 (32- och 64-bitars); Windows Server 2008 eller 2008 R2 (32- och 64-bitars); Windows 7 (32- och 64-bitars); Windows 8 (32- och 64-bitars)

•         512 MB installerat RAM-minne (1 GB rekommenderas)

•         1,5 GB ledigt hårddiskutrymme (Obs! Under installationen skapas tillfälliga filer, och det krävs då mer ledigt hårddiskutrymme än vad som anges här.)

•         En skärmupplösning på 1 024 x 768

•         Internet Explorer 7, 8, 9, 10; Firefox (Extended Support Release); Chrome

•         DVD-ROM-enhet, vid installation från dvd-skiva

•         Maskinvaruacceleration för video är valfritt

För Windows Server 2003 SP2 och Windows XP SP2 för 64-bitars krävs Microsoft Hot Fix KB-930627. Se:

http://support.microsoft.com/kb/930627

 

Installationsanvisningar

 

Använd följande anvisningar för att installera ny programvara eller uppgradera från en tidigare version. Om du installerar en uppgradering kan du behöva uppge någon form av ägarbevis.

 

Så här installerar du Acrobat XI på Windows

 

1. Starta om Windows och stäng av alla antivirusprogram.

 

2. Anslut datorn till Internet.

 

3. Starta installationen:

  • Om du har köpt Acrobat på en dvd-skiva sätter du i skivan.
  • Om du har köpt Acrobat som en filhämtning hämtar du paketet till önskad plats på hårddisken.

 

Du bör säkerhetskopiera det hämtade paketet, helst till en dvd-skiva, innan du installerar programmet. När du dubbelklickar på .exe-filen för att packa upp den:

 

För Windows XP-system,

 

<skapas mappen systemenhet>:\Documents and Settings\<användare>\Skrivbord\Adobe Acrobat XI på skrivbordet.

 

För Windows 7 och 8,

 

skapas mappen systemenhet>:\användare\<användarnamn>\Skrivbord\Adobe Acrobat XI på skrivbordet.

 

När du är klar att installera öppnar du mappen Adobe Acrobat XI och dubbelklickar på setup.exe.

 

Välj önskat språk i installationsfönstret för Adobe Acrobat XI och klicka på ”OK”. Se till att du väljer det språk på vilket du köpte produkten. Klicka på ”Nästa” i installationsfönstret för Adobe Acrobat XI. Installationsprogrammet beräknar hur mycket diskutrymme som behövs och kontrollerar om det finns tidigare versioner. Om det finns en tidigare version av samma Acrobat-produkt klickar du på ”Fortsätt” för att avinstallera det.

 

4. I installationsfönstret måste du ange namn, företag och serienummer. Om du använder produkten i utvärderingsläge eller har köpt en prenumeration (endast Pro) behöver du inte ange något serienummer. Om du anger ett serienummer kontrollerar du att datorn är ansluten till Internet, eftersom serienumret kommer att kontrolleras online. Obs! Om du installerar i utvärderingsläge kan du använda programmet under en 30 dagar lång utvärderingsperiod från första användningstillfället.

 

5. Ange serienumret för din kopia av programmet. Serienumret för köpta produkter med individuell licens finns på utsidan av dvd-fodralet eller på den sida som bekräftade ESD-inköpet (Electronic Software Delivery) via Adobe Store. Du kan även hitta serienumret för ESD-inköp med individuell licens i din onlineorderhistorik på http://www.adobe.com. Serienumret för inköp som gjorts via Adobes licenswebbplats är tillgängligt i dina uppgifter på http://licensing.adobe.com.

 

6. Klicka på ”Nästa” i fönstret Licensaktivering för Adobe. Aktiveringen är en rad enkla och snabba steg (helt anonyma) som utförs av programmet. Mer information om produktaktivering finns på Adobes webbplats på: http://www.adobe.com/go/activation_se/

 

7. Välj installationstyp:

  • Med Standard (detta är standardalternativet) installeras programfilerna för Acrobat, Acrobat Distiller, PDFMaker, Adobes PostScript-skrivardrivrutin för aktuellt system, standardplugin-program och tillbehör.
  • Med Fullständig installeras alla Acrobat XI-funktioner, och detta kräver mest diskutrymme.
  • Med Anpassad kan du själv välja vilka komponenter du vill installera.

 

Obs! Om du vill visa en beskrivning av en komponent väljer du Anpassad och klickar på ”Nästa”. Välj sedan önskad komponent för att se beskrivningen. Klicka på ”Bakåt” om du vill gå tillbaka och välja en annan installationstyp, om du inte vill fortsätta med den anpassade installationen.

 

Klicka på ”Nästa”. Ändra installationskatalog (om så önskas), eller välj standardkatalogen som visas, och klicka på ”Nästa”.

 

8. Klicka på ”Installera” för att fortsätta med installationen. Om det finns några aktiva processer som står i konflikt med installationen uppmanas du att avsluta dessa innan installationen fortsätter. Stäng processerna och klicka sedan i installationsprogrammet för att fortsätta installationen.

 

9. Den sista dialogrutan är ”Installationen har slutförts”. Klicka på ”Slutför”. Nu kan du starta Acrobat.

 

10. När du startar programmet godkänner du licensavtalet för slutanvändare så att du kan börja använda programmet.

 

11. Om du angav ett serienummer under installationen går du till steg 12 nedan. Om du använder Acrobat i utvärderingsläge eller har en prenumeration (endast Pro) visas fönstret ”Inloggning krävs”. I fönstret ”Inloggning krävs” väljer du ”Logga in nu”. Ange ditt Adobe-ID i fönstret ”Logga in”. Om du inte har något Adobe-ID klickar du på ”Skapa ett Adobe-ID” och uppger den information som behövs. Klicka sedan på ”Skapa”. Följ anvisningarna på skärmen för att slutföra processen. Klicka på ”Logga in”. Nu ska du kunna använda Acrobat.

 

12. Om du angav ett serienummer under installationen visas registreringsfönstret. Ange ditt Adobe-ID i registreringsfönstret. Om du inte har något Adobe-ID klickar du på ”Skapa ett Adobe-ID” och uppger den information som behövs. Klicka sedan på ”Skapa”. Följ anvisningarna på skärmen för att slutföra processen med att skapa ditt Adobe-ID och registreringen. Du kan också klicka på ”Hoppa över”. VIKTIGT! Du måste vara ansluten till Internet för att aktivera din kopia av programmet. Du måste aktivera kopian inom 30 dagar. Efter 30 dagar slutar programmet att fungera.

 

Så här av installerar du Acrobat XI på Windows

 

1. Innan du avinstallerar Acrobat XI inaktiverar du produkten. Det gör du genom att välja Hjälp > Inaktivera. När du sedan ska avinstallera programmet öppnar du Kontrollpanelen och väljer Lägg till eller ta bort program.

 

2. Markera Acrobat XI i den lista med program som visas och klicka sedan på knappen Ta bort/Avinstallera.

 

3. Det visas en dialogruta, där du ombeds bekräfta att du vill ta bort Acrobat. Välj Ja för att avinstallera produkten.
